This is a URL shortener Project build in spring boot 


Versions:
Java Version - 17
Spring Version - 3.4.0
Build Tool - Maven 



Dependencies:
Lombok: A library that reduces boilerplate code by auto-generating getters, setters, constructors, etc.
Spring Web: A Spring module for building web applications and REST APIs using HTTP.
Spring Data JPA: A Spring module that simplifies database access using JPA and ORM (Hibernate) instead of writing SQL manually.
Spring SQL (JDBC): A Spring approach for working with databases using raw SQL queries via JDBC templates.

FrontEnd -> React
Backend -> SpringBoot
